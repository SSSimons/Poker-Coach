# Poker-Coach
=======
# Casino Coach Poker 0.5.4

Учебный Android-тренажёр решений в Texas Hold’em на Python и Kivy. Приложение не принимает реальные ставки: фантики являются только внутренними учебными очками.

## Первое открытие

До главного меню запускается обязательный интерактивный курс из пяти глав:

1. поиск лучшей комбинации на пяти board-картах (пять примеров);
2. позиции и порядок действий preflop/postflop;
3. open-raise, диапазоны, sizing 2.5 BB и розыгрыш 7♥6♥;
4. запрет open-limp, dead money и isolation raise против четырёх limper;
5. CHECK, BET, CALL, RAISE и FOLD на postflop.

После завершения один раз начисляется 1000 приветственных фантиков. Прогресс курса хранится локально.

## Режимы

### Блиц-задачи

- один ран содержит ровно 10 задач;
- решение может находиться на префлопе, флопе, тёрне или ривере;
- показываются позиция, крупные изображения карт, pot, stack и визуальная последовательность действий;
- postflop-кнопки учитывают последнее действие: после CHECK доступны CHECK, BET 33%, BET 75% и OVERBET, а против BET — FOLD, CALL, SMALL RAISE и BIG RAISE;
- на preflop, когда board ещё нет, доступны ровно три решения: CALL, OPEN-RAISE/RAISE и FOLD;
- размер preflop-ставки не является отдельным вариантом ответа: sizing задаётся общей стратегией range, а проценты pot используются исключительно postflop;
- один вариант лучший, один нормальный, два ошибочных;
- лучший ответ приносит 20 фантиков, нормальный — 5;
- идеальный ран 10/10 приносит бонус 500 фантиков;
- Free-план содержит два рана и два запроса к ИИ-тренеру.

### EV Battle Solo

Соперник автоматически и случайно меняется в каждой новой раздаче; выбирать его вручную не нужно. Имя и тег сразу обозначают его leak:

- Фолдёр Филипп — слишком часто сдаётся под давлением;
- Тайтовый Тимофей — продолжает в основном с готовой рукой;
- Лимпующая Лена — широко коллирует и любит смотреть следующие карты.

Рука начинается с flop или turn. Карты героя и бота выбираются из реалистичных диапазонов соответствующих позиций, без мусорных сочетаний вроде 42o против 57o. Первым на каждой улице действует игрок без позиции. Кнопки меняются по состоянию торговли: CHECK/BET, CALL/RAISE/FOLD и CALL/RE-RAISE/FOLD. BET и RAISE задаются вручную слайдером; для raise показывается итоговый размер и доплата. Банк, оба stack и вклады текущей улицы считаются раздельно.

Бот не видит карты героя: локальный Monte Carlo оценивает его equity против range позиции соперника и сравнивает его с pot odds. Порог решения затем меняется по профилю: Филипп overfold, Тимофей tight, Лена loose-passive. Визуальная лента показывает последовательность действий, а REPLAY заново проигрывает её в динамике. На Android приложение пытается озвучивать реплики системным TTS. После окончания открываются обе руки; подробный разбор алгоритма остаётся Premium-функцией.

### Community Sandbox на фантики

- один открытый 6-max учебный стол доступен всем без подписки и без минимального баланса;
- обычная раздача Hold’em проходит по улицам flop, turn и river;
- сейчас это локальная песочница против бота, а не сетевой стол с другими людьми;
- фантики нельзя купить, вывести или обменять на деньги.

Настоящие community-столы технически возможны, но потребуют отдельного сервера: аккаунтов, комнат, WebSocket-синхронизации, серверной колоды и расчёта действий, базы данных, reconnect и защиты от подмены клиента.

## Подписка и соцсети

Экран подписки показывает границы Free/Premium, но реальная оплата не подключена. До публикации нужно интегрировать Google Play Billing и серверную проверку покупок. Песочница на фантики остаётся бесплатной.

Кнопки Instagram и YouTube работают как подготовленные точки редиректа. Реальные URL нужно подставить после создания аккаунтов.

## ИИ-разбор

В разделе «ИИ» можно временно подключить OpenAI API key. Ключ хранится только в памяти до закрытия приложения. Для публичного выпуска прямой API-вызов из APK необходимо заменить сервером-посредником с аутентификацией, лимитами и защитой ключа.

## Сборка

Сборка выполняется в WSL из `/home/se/projects/casino_coach`.

Для Samsung и других ARM64-телефонов:

```bash
source /home/se/.venvs/kivy-android/bin/activate
cd /home/se/projects/casino_coach
./tools/build_phone_apk.sh
```

Для Android Studio Virtual Device x86_64:

```bash
source /home/se/.venvs/kivy-android/bin/activate
cd /home/se/projects/casino_coach
./tools/build_emulator_apk.sh
```

Не заменяйте скрипты обычной командой Buildozer: они применяют необходимые патчи упаковки CPython 3.12.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты покрывают покерный оценщик комбинаций, сравнение рук, базовую стратегию, позиционные диапазоны, range-equity и решения всех профилей ботов. `tools/smoke_ui.py` дополнительно проходит весь onboarding, основные режимы и цепочку BET → RAISE → CALL с проверкой сохранения суммы pot + stack.

Приложение предназначено для обучения. Оно не принимает реальные ставки, не гарантирует выигрыш и не является финансовым советом.
